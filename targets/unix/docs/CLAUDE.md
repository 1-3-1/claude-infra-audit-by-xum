## 판단 결과 기준 (공통)

| 결과 | 조건 |
|------|------|
| **양호** | 점검 명령어 결과가 기준을 명확히 충족한 경우 |
| **취약** | 점검 명령어 결과가 기준을 명확히 위반한 경우 |
| **확인필요** | Data 불충분, "파일 내용 확인 필요" 명시, 현장 확인 없이 판단 불가한 경우 |
| **N/A** | 해당 서비스 미설치 또는 해당 OS에서 적용 불가한 경우 |
